## Design Context

### Users

Volunteers and coordinators for **Chittapawan Nadegek Manusya** fill in (or help members fill in) directory entries on phones and small screens—often in community settings, quickly, with occasional follow-up on desktop. Primary job: capture accurate business/member data and find the right person by sector, city, or keyword.

### Brand Personality

**Warm**, **trustworthy**, **grounded** — a civic directory, not a startup dashboard or a generic admin template. The UI should feel approachable for people who are not “power users,” with clear sections, legible type, and calm color that still has character.

### Aesthetic Direction

- **Theme**: Light-first (daytime mobile use). Surfaces read like warm paper; text is high-contrast ink, not gray-on-gray.
- **Typography**: Distinctive editorial display (Libre Bodoni) paired with an accessible, highly readable body face (Atkinson Hyperlegible).
- **Color**: OKLCH-based palette; neutrals tinted toward a warm amber/ochre hue; a single confident accent (deep terracotta/umber) for actions and focus. No cyan-on-dark, no purple gradients, no gradient text.
- **Motion**: Restrained: section reveals, focus rings, button feedback. Full `prefers-reduced-motion` support.
- **Anti-patterns**: Avoid “card grids of three features,” thick left-border stripes on alerts, Inter/Space-Grotesk defaults, and cluttered tables on mobile (use horizontal scroll with clear affordance).

### Design Principles

1. **Mobile-first density** — Thumb reach, large targets, sectioned form; directory as scannable rows/cards with search always visible.
2. **Hierarchy through space** — Tight grouping inside sections, generous separation between sections; avoid identical padding everywhere.
3. **Rare accent** — Color signals primary actions and key filters, not decoration on every row.
4. **Plain language** — Labels match community vocabulary from the intake form; errors are concrete and actionable.
5. **Performance** — Server-side listing with pagination; no client-side waterfalls for directory data beyond the current page.
